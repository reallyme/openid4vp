# ReallyMe OpenID4VP Facade

`reallyme-openid4vp` is the feature-gated Rust facade for the focused
OpenID4VP workspace crates. It re-exports the stable domain, policy, protobuf,
codec, runtime, HTTP, profile, format, and Digital Credentials API surfaces
without collapsing their dependency boundaries.

See the [repository README](../../README.md) for architecture, validation, and
conformance guidance.
